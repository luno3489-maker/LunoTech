# LUNO — Editorial AI Website

An original, responsive, static multi-page website concept for LUNO (@LunoDotTech).

## Pages
- `index.html` — Home
- `vision.html` — Vision
- `product.html` — Product direction (includes clearly labeled non-functional UI concept)
- `use-cases.html` — Potential use cases
- `roadmap.html` — Proposed development path

## Publishing with GitHub Pages
1. Upload **all HTML files and the entire `assets` folder** to the repository root.
2. Go to repository **Settings → Pages**.
3. Choose **Deploy from a branch**, `main`, `/ (root)` and save.
4. Open the Pages URL GitHub provides.
5. If using a custom domain, configure its DNS according to GitHub Pages instructions.

## Notes
- No build tools needed: plain HTML, CSS and JavaScript.
- Logo image included at `assets/luno-mark.png` from the provided artwork.
